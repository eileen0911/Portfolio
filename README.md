# Portfolio Projects

This repository contains selected external demo projects from my portfolio.

## Projects

### 1. RAG_Chatbot

An external demo of an AI infrastructure and RAG chatbot system. The project covers knowledge sync from BookStack, vector search with Qdrant, LLM serving, and a FastAPI-based chat service for grounded question answering.

### 2. Trytt_System

An external demo of a fitness management platform for gyms and personal training studios. The project includes member management, course scheduling, order handling, and operational workflows built around a Django-based system.

### 3. Part_Mapping

An external demo of an AI-assisted BOM part mapping workflow. The project shows how uploaded BOM data can be validated, cleaned, normalized, matched against a PLM part index, and reviewed through an LLM-assisted recommendation flow with CSV-based outputs.
