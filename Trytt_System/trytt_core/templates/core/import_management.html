導入流程
  1. 選擇導入類型
  2. 下載 Excel 模板
  3. 整理數據並填入模板
  4. 上傳檔案
  5. 系統驗證數據
  6. 確認導入
會員數據導入

批量導入會員基本資料

  • 必填欄位：姓名、手機號碼、負責教練、註冊日期、狀態
  • 系統會自動檢查重複的手機號碼
  • 自動分配會員編號
訂單數據導入

批量導入歷史訂單資料

  • 必填欄位：會員手機號碼、訂單日期、課程名稱、購買數量、單價、付款方式、訂單狀態
  • 系統會自動建立課程庫存記錄
  • 自動計算訂單總金額
授課記錄導入

批量導入授課記錄

  • 必填欄位：會員手機號碼、課程名稱、授課日期
  • 系統會自動從會員課程庫存中扣減
  • 庫存不足時導入會失敗
